# Simple Langfuse

Experimenting with different observability, evaluation and tracing products.

A simple Next.js chat app that asks various prompts, and tests different web search settings.
- `nextjs app` : hat app + OpenRouter session logging: 
- `evals`: evals on if it can answer certain questions and which model is best for deep research on it. 

LLMs are accessed via OpenRouter. Tracing via Langfuse.

# Requirements
- OpenRouter API Key
- Langfuse API Key
